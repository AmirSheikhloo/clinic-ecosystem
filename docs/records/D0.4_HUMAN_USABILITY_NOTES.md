# D0.4 short human usability notes (automated timing ≠ human completion)

Environment: Cloud Agent Linux; Windows not re-validated in this session.

Observed interaction design (counts, not stopwatch claims):
- Find patient: search ≥2 chars → select row (≈2 actions after typing).
- Register patient: name fields (+ optional National ID) → submit (target <30s with ready keyboard).
- Single booking: patient → service → resources → time → submit (≈5 controls).
- Multi-service: complete row → «افزودن خدمت به پیش‌فاکتور» → change service/time → «ثبت N نوبت مستقل».
- Arrival: appointment details → «ثبت حضور» (one direct action when permitted).
- Open dossier: appointment/patient links (one action).

Recommend Product Owner timed walkthrough on Windows preview after Docker Desktop is healthy.
