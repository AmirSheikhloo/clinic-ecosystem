# D0.5 Demo dataset

Deterministic synthetic preview data for Task 28. Profiles: `minimal` | `demo` (default) | `performance`.

## Usage

```bash
# Keys for encrypted National ID / phone demo rows (non-production only)
export CLINIC_ENV=test
# see clinic_ecosystem.infrastructure.demo.crypto_hooks.preview_demo_pii_env
```

Loader: `clinic_ecosystem.infrastructure.demo.loader.load_demo_dataset(session, tenant_id=..., profile="demo")`.

Validation: `count_demo_snapshot` / `validate_demo_counts`.

## Targets (demo profile)

See `profiles.py` DEMO: ≥520 patients, ≥10 500 appointments, ≥220 today, ≥110 tomorrow, overlaps, waiting, multi-service groups, ≥5 200 audit events.

Finance/inventory rows are **not** seeded (Category C — no approved DDL).

## Integrity

Relative Tehran dates; valid appointment statuses only; optional PII ciphertext when CLINIC_PII_* present.
